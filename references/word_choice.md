# Word-Choice & Register Reference
# Strict diction control for economics, management, and causal-inference manuscripts

Apply together with `terminology.md` (which fixes *what a concept is called*) and `causal_facts.md`
(which fixes *what is true*). This file fixes *how the surrounding prose is voiced*.

## Three governing rules

1. **Disciplinary priority** — when a word has a settled meaning in economics / causal inference,
   that meaning and its canonical form win. Never let a general-language, literary, or
   news-media synonym override the technical term (e.g. *"平行趋势假设"* → **parallel trends
   assumption**, never "parallel trend hypothesis"; *"工具变量法"* → **instrumental variables (IV)
   estimation**, never "instrumental variable method").
2. **Neutral register** — the tone must sit *between* literary ornament and journalistic hype.
   Avoid both ends: no *"burgeoning tapestry of myriad factors"* and no *"the shocking truth that
   costs skyrocketed"*. Target the middle band in §2.
3. **Spectrum-aware substitution** — when you replace a word, **match its intensity / affect**.
   Do not silently upgrade ("rise" → "soar") or downgrade ("plummet" → "dip") the emotional
   temperature. §3 gives intensity-matched alternatives so the meaning's force is preserved.

## Part 1 — Academic usage conventions (economics / causal inference)

### 1.1 Reporting verbs
- **Prefer**: document, estimate, examine, investigate, find, show, establish, provide evidence
  that, report, quantify, characterize.
- **Restrict**: "prove" — only for a formal proof/theorem, never for an empirical finding.
- **Discourage**: "impact" as a *verb* (use *affect* / *influence*; keep "impact" as a noun, sparingly);
  "utilize" (use *use*); "leverage" as a verb (informal); "exhibit" (over-formal — *show* is fine).

### 1.2 Causality language (tie every verb to the identification)
- **Descriptive** (no design needed): *is associated with*, *is correlated with*, *predicts*,
  *covaries with*.
- **Causal** (only with a valid design; see `causal_facts.md` §4): *affects*, *influences*,
  *increases*, *reduces*, *causes*, *leads to*, *drives*.
- Never upgrade descriptive → causal in phrasing alone.

### 1.3 Hedging — calibrated to evidence strength
- **Ladder (weak → strong)**: may → can → tends to → is likely to → is associated with →
  suggests → is consistent with → indicates → provides evidence that → shows → establishes.
- Pick the **strongest** form the evidence supports; never stack hedges
  ("may potentially possibly").

### 1.4 Fillers, intensifiers, and asserted emphasis — cut on sight
obviously, clearly, of course, it goes without saying, needless to say, very, quite, rather,
really, extremely, highly, particularly (as a bare intensifier), it is worth noting that,
note that (non-technical), as we all know, a growing body of literature (unless cited).

### 1.5 Wordiness and nominalization — de-nominalize
- in order to → **to**
- due to the fact that → **because**
- a large number of → **many**
- make an assessment of → **assess**
- conduct an analysis of → **analyze**
- the problem of X → **X** (delete "the problem of")

## Part 2 — Neutral register: the three-band table

Tone target for all top-journal prose is the **middle band**. The left band reads pretentious;
the right band reads promotional. Neither belongs in a scholarly manuscript.

| Meaning | Literary / ornate (avoid) | Neutral academic (preferred) | Journalistic / hype (avoid) |
|---|---|---|---|
| many | a myriad of, a plethora of | many, numerous | tons of, a boatload of |
| examine | delve into, probe | examine, investigate, analyze | dig into |
| a field | the realm of, the landscape of | the field of, the literature on | the world of |
| increase | burgeon, wax | increase, rise, grow | skyrocket, explode |
| decrease | wane, abate | decline, fall, decrease | plummet, crater |
| cause | engender, beget | cause, lead to, result in | spark, set off |
| important | of paramount import | important, central, key | huge, massive, game-changing |
| surprising | marvelous, wondrous | notable, striking, surprising | shocking, jaw-dropping |
| show | bespeak, attest to | show, indicate, demonstrate | prove (as a hype verb) |
| problem | quandary, predicament | issue, challenge, limitation | crisis, disaster |
| change | metamorphose | change, shift, evolve | shake up, upend |
| use | avail oneself of | use, employ, apply | harness, weaponize |
| clear | transpicuous, perspicuous | clear, evident, straightforward | crystal-clear, no-brainer |
| conclusion | draw to a close | conclude, in sum, overall | wrap up, bottom line |

**Rule**: if a word only appears on the left or right band, replace it with the middle-band form.

## Part 3 — Intensity / affect spectra (intensity-matched replacements)

Each row is a ladder from **low → high** intensity. A star (★) marks the neutral academic default.
Replacements offered for any word should be drawn from the **same neighbourhood** on the ladder.

### Increase
tick up → edge up → **rise ★** → **increase ★** → grow → climb → surge → soar / skyrocket
*Reason*: "surge / soar / skyrocket" import news-media drama; reserve for genuinely large magnitudes and always quantify.

### Decrease
dip → edge down → **decline ★** → **decrease ★** → fall → drop → slump → plunge → plummet / crater
*Reason*: "plunge / plummet / crater" are rhetorical; "decline / fall / decrease" fit neutral findings.

### Magnitude (effect size)
negligible → slight → modest → moderate → **substantial ★** → **large ★** → considerable → dramatic → enormous / massive
*Reason*: report the coefficient; "substantial / large" are safe descriptors, "dramatic / enormous" overclaim.

### Importance
marginal → minor → relevant → **important ★** → central / key → crucial → critical → pivotal → paramount / vital
*Reason*: "important / central" suffice; "pivotal / paramount / vital" are rhetorical inflation.

### Evidence strength
hints at → is suggestive of → **suggests ★** → **indicates ★** → points to → **shows ★** → demonstrates → establishes → proves
*Reason*: match to the identification; "proves" is reserved for formal proofs.

### Causation
**is associated with ★** (descriptive) → covaries with → predicts → **influences / affects ★** (causal) → **increases / reduces ★** → causes → drives → determines → dictates
*Reason*: the left group is descriptive; causal verbs require a design. "Determines / dictates" imply a mechanism you likely did not identify.

### Certainty
possible → plausible → likely → probable → evident → clear → certain → definitive
*Reason*: keep at most one hedge per clause; "certain / definitive" rarely survive peer review.

### Novelty / contribution
extends → complements → contributes to → advances → is the first to (only if true) → revolutionizes
*Reason*: top journals dislike priority claims; "extends / contributes to / advances" are safe.

### Counterintuitive
interesting → notable → **striking ★** → surprising → counterintuitive → paradox → astonishing / stunning
*Reason*: "striking / surprising" are acceptable about once per paper; reserve for real surprises.

### Scope / generalization
in this sample → in this setting → in our context → more broadly → **generally ★** → universally
*Reason*: scope words must match external validity; "universally" is almost always an overclaim.

## Part 4 — Quick substitution sheet (overused / too strong / literary / AI-favoured → neutral)

| Instead of | Use | Why |
|---|---|---|
| delve into | examine | "delve" is overused and slightly literary |
| leverage (verb) | use, exploit (for identification) | "leverage" is business jargon |
| utilize | use | "utilize" is needlessly formal |
| robust (as a generic praise word) | keep only in "robust standard errors / robustness check" | elsewhere it is vague |
| underscore (verb) | highlight, emphasize | "underscore" is journalistese |
| pivotal / crucial (everywhere) | important, key, central | over-emphasis dilutes force |
| a myriad of / a plethora of | many, numerous | ornate padding |
| shed light on | clarify, inform | cliché, low information |
| it is important to note that | (delete; state the fact) | asserted emphasis |
| in today's rapidly changing world | (delete; give the concrete trend) | hype framing |
| groundbreaking / novel paradigm | (state the specific contribution) | unsupported novelty claim |
| play a crucial role | (say what X does, with a magnitude) | empty intensifier |
| multifaceted / nuanced / intricate | complex, detailed | vague filler |
| not only ... but also ... (overused) | (usually a single clause suffices) | mechanical pairing |

## How to apply (feeds SKILL.md Step 5)

1. For each non-technical content word, locate its row in §2 or §3 and move it to the middle band.
2. When substituting, **stay in the same spectrum neighbourhood** (§3) so intensity is preserved;
   give the user one or two alternatives with a one-line reason.
3. Cut §1.4 fillers, de-nominalize §1.5 constructions, and align reporting verbs / hedging
   (§1.1, §1.3) with the evidence.
4. Log every word-level change in Block B under the rationale category **Word choice / Register**.
